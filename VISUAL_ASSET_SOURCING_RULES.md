# Keneflex Visual Asset Sourcing Rules

## Consumer rule
Use a picture when it can explain position, movement, fit, sequence, setup, or product use faster than prose. Visuals should reduce reading, not decorate it.

## Clinical rule
A stock image is eligible only when the depicted movement or setup matches the instruction Keneflex is actually giving. Never use an attractive stretch image as a generic stand-in for a different movement. If Keneflex is only recommending comfortable motion, do not show a forced end-range stretch.

## Licensing rule
For prototype use, prefer public-domain or clearly reusable Creative Commons assets with attribution where required. Do not hotlink paid stock libraries or copy images from retailer/manufacturer sites unless the use is authorized. Production should maintain an asset record with source URL, creator, license, date checked, and any required attribution.

## Useful existing sources identified
- Wikimedia Commons: `Ergonomic-typing.gif` — correct wrist/hand/forearm typing position; Lawrence Berkeley National Laboratory; U.S. federal-government public domain.
- Wikimedia Commons: `Wrist stretch.jpg` — wrist/hand stretch photograph; public domain. Use only if the actual prescribed movement matches.
- Wikimedia Commons: `Exercise Wrist Flexor Stretch.png` — Blausen Medical Communications illustration; CC BY-SA 4.0. Use only with license-compliant attribution/share-alike handling and only when wrist-flexor stretch is actually prescribed.
- Wikimedia Commons: `Exercise Wrist Extensor Stretch.png` — Blausen Medical Communications illustration; CC BY-SA 4.0. Same restrictions.
- Wikimedia Commons category `Home care physical exercises` contains additional region-specific exercise art that can be screened as the content library expands.

## Design standard
1. One idea per image/frame.
2. Relevant body region fills the frame.
3. Direction arrows only when they clarify motion.
4. No text baked into imagery when responsive HTML labeling can do the job better.
5. Mobile-first legibility.
6. Show the exact selected product when demonstrating fit/use.
7. Use before/after or less-helpful/better comparisons for ergonomics where appropriate.
8. Every visual needs an accessible alt description.

## Production roadmap
As Keneflex's intervention library becomes condition- and pattern-specific, source or commission clinically reviewed art for each exact exercise/movement, with dose, stop rule, progression/regression and contraindications stored separately from the image. The recommendation engine decides which visual is eligible; the frontend never chooses a generic image merely because it matches the body part.
